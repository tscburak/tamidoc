# Contributing to Tamidoc Community

Community code is released under Apache-2.0. By submitting a contribution, you offer it to the Community project under the same license. No copyright assignment or Contributor License Agreement (CLA) is currently required. Do not submit code owned by your employer or another party without permission.

Validate changes with `npm run build` and relevant tests in both `apps/api` and `apps/web`. Do not include private Enterprise implementations in public contributions or issue attachments.

Community code may be included in both the Community distribution and the Enterprise distribution that uses it. This contribution process does not publish the source of the proprietary Enterprise modules.
