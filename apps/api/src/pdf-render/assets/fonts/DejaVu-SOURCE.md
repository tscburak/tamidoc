DejaVu 2.37, unmodified TTFs: Serif Condensed (regular, bold, italic, bold italic),
Sans and Sans Mono (regular, bold, oblique, bold oblique). The three families are
also the bounded set of Unicode font substitutes used by PDF import.

Source: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

Archive: `dejavu-fonts-ttf-2.37.zip`. License: `DejaVu-LICENSE.txt` in this directory.
Identical files are served from `apps/web/public/fonts` so browser editing and PDF export use the same glyphs and metrics.
